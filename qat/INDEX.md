# QAT tool index

Generated by `qat.py index`. Load a tool by reading its spec file.

## effort-cost v0.1.0 — ok

From inside a conversation, give a heuristic estimate of the environmental cost (energy, CO2e, water) of answering it at a higher model or reasoning-effort setting versus the current one, in everyday terms, next to what the extra effort would plausibly buy for this particular request.

- **file:** `tools/effort-cost.qat.md`
- **inputs:** thread (text), proposed (text, optional), current (text, optional), where_when (text, optional)
- **outputs:** settings (claims), estimate (scorecard), anchors (claims), value (claims), where (claims), levers (claims), lean (verdict), basis (claims)
- **modules:** settings, estimate

## stress-test v2.0.0 — ok

Challenge the hidden assumptions, blind spots, backfire risks, reversals and ethical echoes of the user's own idea, plan or design, and propose the tweak that makes it more resilient.

- **file:** `tools/stress-test.qat.md`
- **inputs:** idea (text), domain (text, optional), stakes (text, optional)
- **outputs:** core_idea (claim), assumptions (premise_set), risks (claims), strongest_counterargument (claim), lens_findings (text), tweak (claim), tests (claims)
- **modules:** reversal, sharpen, ethical-echo, application-stress, bias-climber
- **hands off to** `truth-weight` when the user wants a verdict between the idea and its strongest counterargument

## toolsmith v0.1.0 — ok

Turn a tool idea into a small, testable QAT tool package (a .qat.md spec, an eval stub with planted cases, a DESIGN.md when choices were made, and runtime adaptation notes), smallest workable thing first.

- **file:** `tools/toolsmith.qat.md`
- **inputs:** idea (text), context (text, optional), neighbors (text, optional)
- **outputs:** brief (claims), reuse (verdict), failures (claims), spec (text), evals (text), design (claims), runtimes (claims), open (claims)
- **modules:** failure-first, runtime-adaptation
- **hands off to** `stress-test` when the requester wants the tool's premise or design probed before building

## truth-weight v2.0.0 — ok

Steelman two competing claims and score which holds up better under historical, empirical, predictive, ethical and burden-of-proof scrutiny, without forcing artificial balance.

- **file:** `tools/truth-weight.qat.md`
- **inputs:** position_a (claim), position_b (claim), evidence (text, optional)
- **outputs:** positions (text), framing (claims), scorecard (scorecard), verdict (verdict), reversal (claims)
- **modules:** burden-of-proof
- **hands off to** `stress-test` when the user wants to probe the winning position further
